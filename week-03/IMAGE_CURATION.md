## Executive Summary & Discernment Philosophy

AI image generation models allow anyone to generate hundreds of visually stunning images in seconds. Because generation is cheap, **judgment and ruthless curation become the ultimate differentiator**. The objective of this assignment is to curate an intentional image set that directly serves the portfolio's core proof statement (*"I build production-ready ML/AI systems with verifiable performance metrics, benchmark notebooks, and clean visual web interfaces"*) while adhering strictly to the Week 3 Identity Kit.

To build trust with Senior Machine Learning Hiring Managers, synthetic AI representations of code, dashboards, or confusion matrices must be eliminated. **Real work demands real work captures**. Real technical artifacts—such as terminal executions, model evaluation matrices, UI screenshots, and personal headshots—are captured directly from running local CLI tasks, Jupyter notebooks, and browser sessions. AI generation is strictly restricted to subtle connective tissue (hero background texture) locked to our identity kit tokens (`#F8FAFC`, `#0F172A`, `#1E40AF`, `#059669`).

## 2. Real Captures vs. AI Stand-ins (Local Task Execution over AI Placeholders)

### Call 1: Case Study 1 — Empirical Confusion Matrix
* **Decision**: Local Model Capture over AI Generation.
* **Why Local Work Beats AI**: AI-generated graphs look visually appealing but hallucinate impossible metric labels (e.g., "Accuracy: 99.999% glow", uncalibrated color scales). Running model evaluation on test data in Python produces verifiable metrics: 9,420 True Positives, 0.942 $F_1$-Score, and 12.4ms inference latency.

### Call 2: Case Study 2 — Zero-Friction Portfolio Engine UI
* **Decision**: Browser Capture over AI Mockups.
* **Why Local Work Beats AI**: Generated UI mockups feature illegible wireframes, misaligned buttons, and impossible web layouts. Capturing the local web interface proves clean responsive HTML, crisp typography (`Plus Jakarta Sans`), and an actual functional 1-click booking modal.

### Call 3: Case Study 3 — Multi-LLM Async Test Harness
* **Decision**: Terminal CLI Task Capture over AI Illustrations.
* **Why Local Work Beats AI**: Terminal tasks executed directly via PowerShell CLI (`python benchmark_harness.py --async`) log real execution timestamps, throughput ($42.4\text{ req/s}$), and latency reductions ($-75.0\%$ cycle time).

### Call 4: Hero Bio & Persona Card
* **Decision**: Real Personal Photo Call over AI Avatar.
* **Why Local Work Beats AI**: Stylized AI avatars (e.g., sci-fi cyber portraits) communicate insecurity or vanity rather than technical professionalism. An authentic photograph of Abdul Raheem establishes transparency and human connection.

## 4. Discernment & Rejection Log ("Kill Your Darlings")

Ruthless curation means killing attractive generated images that fail to serve the proof statement or violate visual guardrails. The following two generated "darlings" were ruthlessly rejected during curation:

### Rejection 1: Futuristic Sci-Fi Glowing Brain (`rejected_sci_fi_brain.png` / `.svg`)
* **Visual Description**: A glowing, hyper-detailed 3D neural brain visualization floating in a dark purple void with floating glowing particles.
* **Why It Was Rejected**: At first glance, this image looked impressive and high-tech. However, it was rejected because it represents pure visual fluff. A glowing sci-fi brain signals pop-science marketing to an ML hiring manager, completely contradicting our voice card (*"direct, technical, precise, metrics-driven, zero fluff"*).
* **Asset Reference**: [`week-03/assets/rejected_sci_fi_brain.svg`](file:///e:/Projects/General%20AI%20Fluency/week-03/assets/rejected_sci_fi_brain.svg)

### Rejection 2: Hallucinated 3D Confusion Chart (`rejected_3d_matrix.png` / `.svg`)
* **Visual Description**: A 3D isometric bar chart with glowing cyan trend lines and sci-fi metric overlays.
* **Why It Was Rejected**: While visually flashy, close inspection revealed that the AI hallucinated non-sensical metrics (`Accurac: 99.999% glow`, `F1-Score: NaN`). Passing off synthetic charts as ML benchmarks destroys engineering credibility. It was killed in favor of the real notebook capture.
* **Asset Reference**: [`week-03/assets/rejected_3d_matrix.svg`](file:///e:/Projects/General%20AI%20Fluency/week-03/assets/rejected_3d_matrix.svg)
