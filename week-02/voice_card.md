# Voice Card & Standing Instruction

> **Voice Card**: `"direct, technical, precise, metrics-driven, zero fluff"`
> **Word Count**: 6 words (Target range: 5 to 7 words)

---

## 1. Standing Instruction (For Claude Project / AGENTS.md)

```markdown
VOICE CARD STANDING INSTRUCTION:
You must write all portfolio copy, project descriptions, bio text, and CTAs in Abdul Raheem's authentic voice defined by 6 words:
"direct, technical, precise, metrics-driven, zero fluff"

Rules:
1. Lead with the core technical problem and empirical metrics (e.g. F1-score, latency ms, memory footprint).
2. Avoid emotional filler, fluff, or generic corporate marketing jargon.
3. Focus strictly on what was built, key decisions made, and verifiable outcomes achieved.
4. Banned words: "results-driven", "cutting-edge", "synergy", "passionate", "seamlessly", "game-changer", "world-class".
```

---

## 2. Voice Breakdown & Definitions

| Word | Operational Definition | Example Application |
| :--- | :--- | :--- |
| **Direct** | Starts with the conclusion; no long-winded intro preamble. | *"Built a real-time lane detection PyTorch model running at 12ms per frame."* |
| **Technical** | Uses exact engineering terminology rather than high-level abstractions. | *"Trained using PyTorch with AdamW optimizer, FP16 mixed precision, and custom loss evaluation."* |
| **Precise** | Quantifies assertions with concrete numbers and operational parameters. | *"F1 score of 0.94 on 10,000 validation images; reduced model size from 140MB to 42MB."* |
| **Metrics-driven** | Every claim is backed by a verifiable score, notebook link, or latency measurement. | *"Benchmarked against baseline models in `w04_baseline_score.ipynb`."* |
| **Zero Fluff** | Cuts filler words, corporate jargon, and self-congratulatory claims. | *Replaces "innovative state-of-the-art solution" with "lightweight REST API endpoint".* |

---

## 3. Banned Phrase Directory

The following terms are strictly prohibited across all portfolio copy:
- ❌ *"Results-driven AI enthusiast..."*
- ❌ *"Passionate about leveraging cutting-edge technology..."*
- ❌ *"Delivering seamless end-to-end user experiences..."*
- ❌ *"Synergizing machine learning with strategic vision..."*
- ❌ *"Next-generation innovative solutions..."*

---

## 4. Operational Checklist for AI Tutor

When reviewing any case study or portfolio copy:
- [x] Does the text state numbers/metrics in the first two sentences?
- [x] Can the reader immediately link to a benchmark notebook or code repository?
- [x] Have all 5 banned phrase patterns been eliminated?
- [x] Does it sound like an engineer presenting empirical data to an engineering lead?
